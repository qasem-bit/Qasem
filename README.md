# ENDO / Clinical Notes PWA

A responsive, offline-ready endocrine study companion based on the uploaded DR.TA7 Endocrine Notes PDF.

## Features
- Topic-based clinical summaries and search
- Saved topics, review tracking, and personal notes stored in `localStorage`
- Quick quiz and flashcards
- Export study data as JSON
- Installable PWA and service-worker offline cache

## Deploy
Upload all files to a GitHub repository and enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` / root.
